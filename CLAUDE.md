# Roblox-style story videos (Blender engine)

This folder makes vertical (1080×1920) animated shorts with Roblox R6-style characters for TikTok and
YouTube: **"What if…"** (main format) and **"In this town…"** absurd / cringe stories. Everything is
generated by code: no manual animation, no CapCut.

- Talk to the user in **Russian**. Scripts, captions and titles are in **English** (US audience).
- When the user gives a video idea, use the **`/episode` skill** (`.claude/skills/episode/SKILL.md`).
- Style benchmark: `STYLE_REFERENCE.md` (bright @kr.editzx0 look).

## Pipeline

```
idea -> script.md + shots.json -> validate -> voice (ElevenLabs, Edge TTS fallback)
     -> [direct (storyboard.json) -> compile (shots.json)] -> build (Blender)
     -> sheet + motion_qa (contact_sheet.png, motion_sheet.png, visual_qa.json)
     -> raw render -> edit (voice, music, sfx, captions, transitions) -> thumb -> publish/<ep>/
```
One command: `python pipeline/make.py episodes/<ep>` (preview) / `--direct` / `--motion-qa` / `--final` / `--only a,b` / `--from stage`.

| File | Runs in | Job |
|---|---|---|
| `pipeline/make.py` | Python | orchestrates every stage, contact sheet, motion QA, thumbnail, publish package |
| `pipeline/director.py` | Python | Cinematic Director Agent: generates intermediate `storyboard.json` |
| `pipeline/compiler.py` | Python | Shot Compiler: validates & compiles `storyboard.json` <-> `shots.json` |
| `pipeline/visual_qa.py` | Python | static + 3-point motion QA report (`render/visual_qa.json` + `render/motion_sheet.png`) |
| `pipeline/vocab.py` | Python | the engine vocabulary (print it before writing a script) |
| `pipeline/validate.py` | Python | checks shots.json against vocabulary + 10 cinematic/continuity QA rules |
| `pipeline/voiceover.py` | Python | ElevenLabs (or Edge TTS) per shot + word timings -> `timing.json` |
| `pipeline/eleven.py` | Python | ElevenLabs client (`check`, `voices`); key from `.env` `ELEVENLABS_API_KEY` |
| `pipeline/eleven_sfx.py` | Python | one-time ElevenLabs SFX library -> `public/audio/sfx/*.mp3` (`--list`, `--only`) |
| `pipeline/episode.py` | Blender | builds the episode scene: sets, cast, animation, cameras |
| `pipeline/render.py` | Blender | raw video / contact-sheet stills / thumbnail still |
| `pipeline/edit.py` | Blender | VSE edit: audio mix, captions, hook title, transitions -> `out/*.mp4` |
| `pipeline/frames.py` | Blender | stills of any frames from any .blend (for checking) |
| `pipeline/roblox_rig.py` | Blender | R6 character generator + face atlas (`PRESETS`, `FACE_NAMES`) |
| `pipeline/roblox_motions.py` | Blender | poses (`POSES`) and motions (walk, jump, laugh, …) |
| `pipeline/roblox_sets.py` | Blender | locations, marks, dressings (day/night/sunset) |
| `pipeline/props.py` | Blender | 54 props (`PROP_KINDS`): in a hand or placed in the world (shot `place`) |
| `pipeline/prop_lineup.py` | Blender | renders every prop -> `public/roblox/props_lineup.png` (run after prop changes) |
| `pipeline/catalog.py` | Blender | rescans assets -> `public/roblox/catalog.json` (run after asset changes) |
| `pipeline/make_audio_assets.py` | Python | synthesizes the sfx + music library in `public/audio/` |
| `pipeline/build_sets.py` | Blender | rebuilds `public/roblox/sets/*.blend` |

Assets: `public/roblox/characters/*.blend` (cast), `public/roblox/sets/*.blend` (locations),
`public/audio/{sfx,music}` (ElevenLabs / dropped-in files; they override the numpy fallbacks in `*/synth/`),
`public/audio/eleven_voices.json` (ElevenLabs voice per character),
`public/fonts/caption.ttf` (optional caption font, else Segoe UI Black).
Formats: `formats/<name>/FORMAT.md` (writing guide) + `format.json` (voice, caption style, music, hashtags).
Episodes: `episodes/<ep>/` (shots.json, script.md, audio/, timing.json, <ep>.blend, render/, out/).
Upload-ready files: `publish/<ep>/`.

Blender: `C:\Program Files\Blender Foundation\Blender 5.1\blender.exe` (override with env `BLENDER`).
Blender 5.x API notes: VSE uses `sequence_editor.strips`; actions are layered (use the `fcurves_of`
helper in episode.py); look shader nodes up by type, not name.

## Rules
- Adding a pose / action / prop / set: change the engine module, then `vocab.py` (actions list; props are read from props.py), re-render `prop_lineup.py` for props
  and `validate.py` if needed, re-run `catalog.py` for new sets/characters, and test with `episodes/test_engine`
  (`python pipeline/make.py episodes/test_engine --only build,sheet`, then look at the contact sheet).
- Never fix a single episode by hacking engine code; the engine must stay general.
- Render jobs are slow (preview ≈0.3 s/frame, final several times that): run them in the background.
- Legacy, do not use: `pipeline/legacy/` (old blocky engine), `public/characters/`, `public/sets/`,
  `episodes/_legacy/`.
- Nothing gets uploaded or posted automatically; the user uploads from `publish/`.
- The ElevenLabs key lives only in `.env` (see `.env.example`). Never ask for it in chat, never write it into code,
  shots.json, logs or memory. No key -> voice falls back to Edge TTS and sfx to the synth library.
